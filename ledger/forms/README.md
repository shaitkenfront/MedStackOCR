# 医療費集計フォーム（国税庁）

`iryouhi_form_v3.1.xlsx` は、国税庁が配布している「医療費集計フォーム」Ver.3.1 です。
明細台帳から確定申告用の資料を作るときのひな形として、そのまま使います。

## 書き込み方（`ledger/tax_form.py`）

確定申告書等作成コーナーは、入力規則やシートの保護を外したフォームを読み込めないことがあります。
そのため Excel ライブラリで開いて保存し直すのではなく、入力欄（`医療費集計フォーム` シートの 9〜1003 行目）の
セルだけを XML で書き換え、それ以外のファイルはバイト単位でそのままコピーしています。

| 列 | 項目 | 制限 |
| --- | --- | --- |
| B | 医療を受けた人 | 10文字以内 |
| C | 病院・薬局などの名称 | 20文字以内 |
| D〜G | 医療費の区分（診療・治療／医薬品購入／介護保険サービス／その他の医療費） | 該当する列に「該当する」 |
| H | 支払った医療費の金額 | 0〜999,999,999 の整数 |
| I | 左のうち、補填される金額 | 0〜999,999,999 の整数 |
| J | 支払年月日（任意） | 文字列（`YYYY/MM/DD` で書き込む） |

国税庁がフォームを改訂したときは、新しいファイルに差し替えて、上の列の配置が変わっていないかを確認すること。
